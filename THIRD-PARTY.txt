Little Tides is an original game prototype. All visual art and sound in the
game are generated by its source code. Fonts use Windows system fonts, with
pygame's packaged font as fallback.

Bundled dependencies include:

Python 3.12.14, Python Software Foundation license.
See licenses/Python-LICENSE.txt and https://www.python.org/

pygame-ce 2.5.8, GNU Lesser General Public License 2.1.
Unmodified package. See licenses/pygame-LGPL-2.1.txt.
Source: https://github.com/pygame-community/pygame-ce/tree/2.5.8
The pygame modules and SDL libraries remain separately loadable files under
_internal/pygame; compatible modified versions can be substituted.

PyInstaller 6.22.3 bootloader, GPL with bootloader exception permitting
distribution of bundled applications. See licenses/PyInstaller-COPYING.txt.
Source: https://github.com/pyinstaller/pyinstaller/tree/v6.22.3

pygame-ce bundles SDL2 and its image, mixer, font and codec libraries.
Project and license references:
SDL2 / SDL_image / SDL_mixer / SDL_ttf: https://www.libsdl.org/license.php
FreeType: https://freetype.org/license.html
libpng: http://www.libpng.org/pub/png/src/libpng-LICENSE.txt
libjpeg-turbo: https://github.com/libjpeg-turbo/libjpeg-turbo/blob/main/LICENSE.md
libtiff: https://libtiff.gitlab.io/libtiff/misc.html
libwebp: https://github.com/webmproject/libwebp/blob/main/COPYING
libogg / libopus / libopusfile: https://www.xiph.org/licenses/
libwavpack: https://github.com/dbry/WavPack/blob/master/COPYING
libxmp: https://github.com/libxmp/libxmp/blob/master/COPYING.LIB
PortMidi: https://github.com/PortMidi/portmidi/blob/master/license.txt

Editable game source is supplied in little-tides-source.zip alongside this
game distribution. The source includes reproducible run and build steps.
